unless `FormerlySerializedAs` is added (none needed so far). Generated by the readability pass; one section per commit.

## Verification notes
Reflection and CLI strings reference member names (`SmokeTest -overrides p.<field>=...` uses CarParams field names via reflection; `EngineOverrunAudioTests` reads the private field `angularVelocity`). CarParams fields are therefore NOT renamed in this pass; private names are updated together with their reflection users.
